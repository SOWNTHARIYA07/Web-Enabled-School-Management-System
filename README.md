# Web Enabled School Management System (WESMS)

A web-based application to manage school operations efficiently.

## 💻 Tech Stack
- Java, Spring Boot
- Thymeleaf (Template Engine)
- MySQL (Database)
- Bootstrap 5 (Frontend)
- Spring Data JPA & Hibernate

## 📌 Modules
Admin | Teacher | Student | Parent |
Attendance | Marks | Fee | Performance Analysis |
Notification | Feedback | Report

## 🚀 How to Run
1. Clone this repository
2. Open in Eclipse or IntelliJ
3. Configure MySQL in application.properties
4. Run as Spring Boot Application
5. Open browser → http://localhost:8080
